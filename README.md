# README 

### Personalized Behavioral Guidance for Wellbeing & Mental Health

---

## Overview

This is a Data Science and AI-powered wellbeing application designed to transform generic wellness advice into personalized behavioral guidance.

The project combines:

* Data Science,
* Machine Learning,
* Behavioral Psychology,
* Mental Wellbeing,
* Lifestyle Analytics,
* AI-generated recommendations

to help users better understand their lifestyle habits and receive actionable recommendations to improve their wellbeing.

Rather than offering generic wellness content, the system analyzes behavioral patterns and generates personalized guidance aimed at increasing:

* consistency,
* engagement,
* motivation,
* and long-term wellbeing outcomes.

---

# Project Vision

Modern wellness platforms often inspire users temporarily, but many users struggle to:

* maintain consistency,
* apply advice in daily life,
* stay motivated long-term,
* and feel personally understood.

This project aims to solve this issue by creating:

> A personalized behavioral guidance system powered by Data Science and AI.

The application bridges:

* lifestyle tracking,
* behavioral analysis,
* wellbeing scoring,
* and AI-generated recommendations.

# Main Features

## Personalized Lifestyle Score

Users enter lifestyle and wellbeing-related information such as:

* sleep quality,
* stress levels,
* exercise habits,
* mindfulness routines,
* social balance,
* work-life balance,
* nutrition patterns.

The model then calculates a personalized wellbeing/lifestyle score.

---

## Machine Learning Recommendations

The system identifies:

* behavioral weaknesses,
* high-impact lifestyle improvements,
* and potential habit adjustments.

It then generates:

* personalized recommendations,
* micro-habit suggestions,
* and practical wellbeing improvements.

---

## AI-Powered Behavioral Guidance

Using OpenAI integration, the application generates:

* personalized wellbeing advice,
* motivational guidance,
* practical next steps,
* emotionally intelligent recommendations.

This creates a more human and engaging experience compared to static wellness advice.

# Machine Learning Workflow

## 1. Data Collection

The project uses a lifestyle and wellbeing dataset containing variables related to:

* stress,
* sleep,
* exercise,
* mindfulness,
* emotional wellbeing,
* work-life balance,
* healthy habits.

---

## 2. Data Cleaning

The dataset was cleaned by:

* handling missing values,
* converting inconsistent data types,
* removing invalid entries,
* standardizing variables.

---

## 3. Exploratory Data Analysis (EDA)

EDA was performed to:

* identify correlations,
* analyze behavioral patterns,
* understand lifestyle influences on wellbeing,
* detect important predictive features.

---

## 4. Model Training

A Machine Learning model was trained to predict wellbeing/lifestyle scores based on user behavior.

The workflow included:

* train/test splitting,
* feature preprocessing,
* model fitting,
* evaluation and optimization.

---

## 5. Recommendation Logic

The system analyzes user inputs and identifies:

* areas of imbalance,
* highest-impact improvements,
* realistic behavior changes.

Recommendations are then generated dynamically.
